# حكايا

قارئ روايات عربي (RTL) بفصول متتابعة، وترجمة عربية/إنجليزية، وحفظ آخر موضع قراءة.

القصص الثلاث المضمّنة أصلية ومكتوبة لهذا التطبيق. التطبيق لا يسحب ولا ينسخ روايات من مواقع التجميع.

## التشغيل

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000).

## الاختبار والبناء

```bash
npm test
npm run build
```

## ماذا يفعل

- كتالوج وبحث
- صفحة الرواية وقائمة الفصول
- قارئ: التالي/السابق، ثيمات ليل/دافئ/ورق، حجم خط
- حفظ التقدّم في `localStorage`: آخر رواية/فصل + موضع التمرير + شاشة مكتبتي
- قراءة رواية من ملف JSON على [/import](http://localhost:3000/import)

## قراءة ملف JSON

1. افتح `/import`
2. أسقط ملف `.json` أو الصق النص
3. الرواية تتحفظ على الجهاز وتتفتح للقراءة

فورمات بسيط:

```json
{
  "title": "اسم الرواية",
  "author": "الكاتب",
  "chapters": [
    {
      "title": "الفصل الأول",
      "text": "فقرة.\\n\\nفقرة ثانية."
    }
  ]
}
```

مثال جاهز: [`/examples/hikaya-novel.sample.json`](./public/examples/hikaya-novel.sample.json)

ارفع قصصك الأصلية أو المرخّصة فقط. التطبيق لا يسحب روايات من مواقع التجميع.
